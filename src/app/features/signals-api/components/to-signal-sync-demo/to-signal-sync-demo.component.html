toSignal(): requireSync vs initialValue

requireSync solo para fuentes que emiten INMEDIATO (ej. BehaviorSubject). Para async, usa initialValue.

Sync (BehaviorSubject + requireSync): {{ syncValue() }}

Async (interval + initialValue): {{ asyncValue() }}

  • requireSync: true significa: “esta fuente DEBE emitir en el momento de suscribirme”. Si la fuente emite después (async), Angular tira error al crear el signal.
  • initialValue es el valor inicial de la UI mientras todavía no llegó la primera emisión real. Te evita estados ambiguos como undefined.

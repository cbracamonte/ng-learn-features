API con RxJS

Objetivo: manejar loading/error/data con stream de estado manual.

  • BehaviorSubject guarda el último estado emitido en memoria del cliente (no cache HTTP).
  • Si no emites un estado intermedio vacío al cambiar params, la UI puede seguir mostrando el dato anterior.
  • Con RxJS, loading/error/data lo modelás vos manualmente en el stream de estado.
  • Más control: puedes decidir entre “limpiar UI en loading” o “mantener valor previo” según tu UX.

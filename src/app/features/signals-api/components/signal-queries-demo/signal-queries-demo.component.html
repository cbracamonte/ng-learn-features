Signal Queries (viewChild/viewChildren)

Caso: panel de tareas que accede al input y a filas del DOM de forma reactiva, sin ngAfterViewInit.

  • viewChild() y viewChildren() devuelven signals tipados y reactivos.
  • Cuando cambia el DOM (mostrar/ocultar input o agregar/quitar filas), la query se actualiza sola.
  • contentChild() / contentChildren() aplican la misma idea, pero sobre contenido proyectado.

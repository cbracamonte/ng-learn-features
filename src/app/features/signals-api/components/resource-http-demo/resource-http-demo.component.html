API con resource()

Objetivo: resolver loading/error/data declarativamente con params reactivos.

  • resource puede dejar value() como undefined mientras carga nuevos params.
  • cache: 'force-cache' puede disimular el gap en red rápida, pero no lo elimina en redes lentas.
  • Para UX estable usamos keep previous value con linkedSignal (visibleTodos).
  • Este patrón es clave para casos reales tipo paginación, filtros y búsquedas remotas.

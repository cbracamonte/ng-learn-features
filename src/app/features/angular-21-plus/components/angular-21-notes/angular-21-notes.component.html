Notas senior Angular 21+ (visual + importantes)

✅ Qué trae valor real en Angular 21+

  • Zoneless default: menos magia, menos monkey patching y CD más explícito.
  • Signal Forms: modelo signal como fuente de verdad + validación reactiva declarativa.
  • httpResource: GET reactivo con estado async expuesto como signals.

🧠 Definiciones senior

  • Experimental no significa “malo”; significa API con riesgo de cambio. No la metas a producción a ciegas.
  • Source of truth: en Signal Forms el modelo signal manda; el form tree no debe convertirse en segunda base de datos.
  • Reactive fetch: httpResource modela lectura dependiente de estado, no escritura de negocio.

🛠️ Notas importantes

  • Si usás httpResource, necesitás provideHttpClient().
  • En Signal Forms, para arrays con @for, trackeá por identidad del field, no por índice suelto.
  • En validaciones cross-field, decidí DÓNDE vive el error: campo puntual, varios campos o nivel form.

⚠️ Anti patrones

  • Usar Signal Forms para reescribir todo el proyecto “porque es nuevo”. Migrá donde aporte valor.
  • Mezclar Reactive Forms + Signal Forms sin estrategia. La interop existe, pero no para vivir en híbrido eterno.
  • Usar httpResource para POST/PUT/DELETE. Eso te mezcla fetching reactivo con mutations de negocio.
  • Leer resource.value() sin guardas cuando puede haber error o estado pendiente.

📌 Regla arquitectónica

Adoptá Angular 21+ por claridad de modelo mental, no por moda. Si la API nueva no reduce acoplamiento, complejidad o boilerplate real, todavía no te compró nada.

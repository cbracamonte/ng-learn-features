02 · Valor agregado de Angular

Angular convierte HTTP en una arquitectura integrable

El valor no es solamente tener un wrapper para fetch. Angular integra HTTP con inyección de dependencias, interceptors, testing, RxJS, signals y SSR.

Valor agregado de Angular para comunicación HTTP
Necesidad frontend Angular aporta Regla Senior
Requests tipados HttpClient con genéricos y opciones HTTP El tipo no valida runtime; parsea o valida contratos críticos.
Políticas transversales Interceptors funcionales Auth, correlation-id, logging, timeout y cache no deben repetirse en cada service.
Metadatos por request HttpContext Permite opt-in/opt-out sin headers falsos enviados al backend.
Estado reactivo de request httpResource sobre HttpClient Es experimental; úsalo con criterio y encapsula la adopción.
SSR sin doble fetch transferCache / integración SSR Cuida privacidad, headers y datos dependientes de usuario.

Interceptors funcionales

  • Angular los recomienda por comportamiento más predecible en configuraciones complejas.
  • Forman una cadena alrededor del request/response.
  • HttpRequest y HttpResponse son mayormente inmutables; se usa clone().
  • Pueden transformar, reintentar, medir, autenticar, cachear o construir respuestas sintéticas.

httpResource y signals

  • Expone valor, estado y error como recursos/señales para templates modernos.
  • Se actualiza cuando cambian las señales que alimentan el request.
  • Conserva interceptors porque se apoya en HttpClient.
  • Al ser experimental, evita acoplar toda la arquitectura pública sin una capa propia.

Accordion pattern

Angular Aria coordina triggers y panels: roles, aria-expanded, aria-controls, navegación por teclado y lazy content.

El trigger queda vinculado al panel con atributos ARIA. Esto no es decoración: es contrato para tecnología asistiva.

Probá moverte entre headers con flechas. Ese comportamiento parece menor, pero para accesibilidad ES EL PRODUCTO.

ngAccordionContent renderiza el contenido cuando hace falta. Accesibilidad y performance no son enemigos.

Tradeoff: Angular Aria te da comportamiento accesible, no diseño visual. Fantástico para design systems; demasiado trabajo si solo querés prototipar.

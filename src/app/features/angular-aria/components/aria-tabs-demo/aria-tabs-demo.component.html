Tabs pattern

Tabs no son botones sueltos con display: none. Son una relación entre tablist, tabs y tabpanels con foco y selección coherentes.

  • Patrones
  • Teclado
  • Errores
Angular Aria incluye patrones como accordion, tabs, menu, toolbar, listbox, combobox, tree y grid. No son “componentes lindos”: son comportamiento accesible reutilizable.
En esta demo, el tablist usa roving tabindex y selección al seguir foco. Probá Tab para entrar y flechas para moverte. Si no testeás teclado, no sabés si tu componente existe para todos los usuarios.
Error típico: agregar role="tab" a mano y olvidarte de foco, selección, relación con panel y estados disabled. ARIA no arregla HTML roto; ARIA mal usado lo empeora.

Criterio senior

Usá Angular Aria cuando querés comportamiento accesible headless. Si lo único que necesitás es un botón, usá <button>. Menos magia, más fundamentos.

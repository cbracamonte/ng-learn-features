Template Control Flow (Angular)

Ejemplos prácticos y comparables de la sintaxis moderna: @defer, @placeholder, @loading, @error, @if y @for.

Guía de lectura rápida (didáctica)

  1. on immediate: carga apenas Angular puede.
  2. on viewport: NO carga hasta que el bloque entra en pantalla (scroll).
  3. on interaction: carga por click/interaction explícita.

Tip: abrí DevTools/Network y vas a ver cómo cambia el momento de carga según el trigger.

1) @defer on immediate (arriba)

Se dispara enseguida. Este bloque te sirve como referencia de “carga temprana”.

@defer (on immediate) { } @placeholder {

Placeholder inmediato...

} @loading (minimum 500ms) {

Loading inmediato...

}

2) @defer on interaction

Solo se carga cuando interactuás con el botón.

@defer (on interaction(interactionTrigger)) { } @placeholder {

Esperando interacción del usuario...

} @loading {

Loading...

}

3) @defer when signal

Se activa cuando una condición reactiva pasa a true.

@defer (when showSignalBlock()) { } @placeholder {

Condición en false. Todavía no se carga el bloque.

} @loading {

Loading condicional...

}

Sección de contraste: viewport vs immediate

Ahora sí es didáctico: este bloque está deliberadamente lejos del inicio. Hasta que no hagas scroll, no debería cargarse.

Spacer intencional para sacar el bloque de on viewport del primer viewport. Bajá para dispararlo.

4) @defer on viewport (abajo, fuera de pantalla inicial)

Este es el cambio clave: no carga al inicio, recién cuando entra en el viewport.

@defer (on viewport) { } @placeholder {

Placeholder viewport: todavía no entró al área visible.

} @loading (minimum 500ms) {

Loading por viewport...

}

5) @error en @defer

Muestra fallback de error cuando el contenido diferido falla.

@defer (when showErrorDemo()) { } @placeholder {

Presioná el botón para disparar el defer.

} @loading {

Intentando cargar...

} @error {

Error capturado por @error. Este es el fallback recomendado.

}

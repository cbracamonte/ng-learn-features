Criterio senior

  • Usá template bindings para la UI normal. No metas DOM imperativo porque sí.
  • Si necesitás medir o integrar librerías DOM, usá afterNextRender, afterEveryRender o afterRenderEffect.
  • Preferí fases explícitas: write para escribir layout, read para medir.
  • mixedReadWrite existe, pero si lo usás por comodidad estás comprando deuda de performance.
